# Локальные модели

Веса не хранятся в Git. Runtime принимает только заранее подготовленный локальный каталог. Для каждого набора должны быть сохранены источник, точная revision, лицензия и SHA-256 в отдельном манифесте.

Публикуемые примеры описывают T-one, Whisper large-v3 и обязательную Silero VAD. Фактические `models/t-one`, `models/whisper-large-v3` и `models/whisper-vad` создаются только во время контролируемого staging и исключены из Git/release ZIP.
